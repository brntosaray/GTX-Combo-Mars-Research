# Evidence, confidence, and release policy

**As of 2026-11-17:** No new receiver connection or binary inspection was performed during creation of this public repository. Current claims are transcribed from historical operator conversations and the operator's private project index. Full raw logs and original firmware artifacts have not been imported.

Labels used here:

- **OPERATOR_REPORTED:** earlier operator described or demonstrated a result in a conversation; the public repository does not contain the full raw evidence.
- **DOCUMENTED_IDENTIFIER:** filename, build, code or checksum preserved from earlier technical notes, not freshly rehashed here.
- **INFERRED:** a possible explanation, explicitly not established experimentally.
- **OPEN:** issue observed or reported without a verified final resolution.
- **UNVERIFIED:** not tested or insufficient evidence.
- **USER_DECISION:** a boundary or preservation instruction, not a hardware measurement.

For each new report include the *actual device model*, board revision if readable, Mars build/date, relevant firmware assets and hashes, observation date, exact reproduction conditions, redacted console excerpts and independent pass/fail outcome.

Do not upgrade a historical claim to a current verification merely because it is copied to GitHub. If new evidence changes a past statement, add a dated correction, retain previous history and say exactly what was confirmed.

Do not publish login tokens, passwords, serial numbers, private network details, full channel lists tied to subscriptions, account data or vendor-owned binary firmware. When copying logs, remove identifiers and review every line first.

Do not confuse this Mars track with CoreELEC or OpenATV. A fix on one kernel / firmware build never establishes compatibility with another.
