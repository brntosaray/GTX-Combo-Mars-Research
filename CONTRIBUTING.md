# Contributing

Thank you for helping with GTMedia GTX Combo **Android Mars** research.

## Submission checklist

- Identify **GTX Combo** versus **GT Combo**, exact firmware/build date and hardware revision if known.
- Record issue symptoms, expected behavior, test conditions, date and relevant affected components.
- Label the evidence: OPERATOR_REPORTED, DOCUMENTED_IDENTIFIER, INFERRED, OPEN or UNVERIFIED, or provide an independently verifiable test log.
- Redact passwords, tokens, account IDs, sensitive device identifiers, network information and any proprietary data.
- Publish only materials you have the rights to redistribute. **No OTA archives, closed-source firmware, vendor APKs, patched proprietary drivers, partition images or private captures.**
- Do not propose destructive flashes, mismatched FE drivers, or edits to a receiver's working environment without explicit user authorization and validation.

Readable documentation, independent test observations and source-level contributions are preferable to unsupported claims.

No project-wide license currently grants third parties permission to copy or redistribute code or proprietary materials.
